# Task Manager App

A Task Manager web application built with React and React Router, featuring authentication flow, task CRUD functionality, and protected routes.

## WHAT I BUILD

- User Registration & Login
- Authentication
- Create Tasks
- View Tasks
- Edit Tasks
- Delete Tasks
- Protected Routes
- React Router Navigation
- Global State Management[Context API]
- Responsive Task Manager UI[Tailwind CSS]

## REACTJS CONCEPTS COVERED

- ReactJS
- Components & Props
- State Management
- useState
- useEffect
- useContext
- Context API
- React Router
- Controlled Forms
- Conditional Rendering
- CRUD Operations
- Reusable Components
- Component Architecture

## Getting Started

1. Install dependencies:
   npm install

2. Start the development server:
   npm run dev
